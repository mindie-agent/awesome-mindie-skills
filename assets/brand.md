# Brand assets

[中文](brand.zh.md) | English

The README banners pair an Awesome-themed version of the mindie-agent icon with the catalogue title, Ascend inference scope, and community audience. The white mascot wears black sunglasses against its purple tile. Both SVG banners embed the same PNG so that they render as self-contained images.

The organization icon was retrieved from the [mindie-agent GitHub organization](https://github.com/mindie-agent) on 2026-10-15 ([avatar source](https://avatars.githubusercontent.com/u/322608234?v=4&s=256)). The icon retains its owner's rights. The catalogue's original artwork uses the repository's CC0-1.0 license.

| Asset | Intended use |
|---|---|
| [mindie-agent-avatar.png](mindie-agent-avatar.png) | Original organization icon snapshot; 256 × 256 PNG. |
| [mindie-agent-awesome.png](mindie-agent-awesome.png) | Awesome sunglasses adaptation, displayed in both README banners. |
| [logo.svg](logo.svg) | Supplementary catalogue mark; 128 × 128 viewBox. |
| [logo-mono.svg](logo-mono.svg) | Single-color catalogue mark for light backgrounds and print. |
| [banner-light.svg](banner-light.svg) | Light README banner; 1200 × 320 viewBox. |
| [banner-dark.svg](banner-dark.svg) | Dark README banner; 1200 × 320 viewBox. |

The README uses a picture element to select the dark banner when supported, with the light banner as fallback. The adjacent Markdown title and introduction retain the name and purpose as readable text.

## Palette

- Organization icon: preserve the supplied purple and white artwork.
- Teal: `#0F766E` for light-banner accents; `#5EEAD4` on dark backgrounds.
- Slate: `#0F172A` for text or dark backgrounds.
- Light text: `#F8FAFC`.

Preserve the icon's aspect ratio and transparency. When updating the Awesome adaptation, update the embedded PNG in both SVG banners and preview both themes. For a later social preview, use a separate 1280 × 640 composition with the same Awesome icon, title, and subtitle.
